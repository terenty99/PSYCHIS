# PSYCHIS — Spatial Knowledge Engine

> *A contemplative, warm white-grey spatial knowledge sanctuary inspired by cyber-philosophical protocols and organic thought topology.*

---

## Overview

**PSYCHIS** (inspired by the *Psyche* cognitive processor and the Japanese philosophy of negative space *Ma*) is a next-generation spatial research and ideation engine. It replaces harsh, clinical dark-mode cyber dashboards with a **sunlit concrete atelier aesthetic featuring spatially-correct architectural topographic contour textures, viscous fluid physics, and high-visibility organic Bézier linkages**.

---

## Core Features

- 🏛️ **Contemplative White-Grey Design System**: Warm-leaning greys (`#F8F7F5`, `#E8E6E3`, `#4A4540`) passing WCAG 2.1 AAA contrast benchmarks with scalable architectural topographic isoline contours.
- 〰️ **High-Visibility Organic Linkages**: Dynamic cubic Bézier paths with relationship-influenced trajectory biases (`ORIGIN_URL`, `COUPLED_SYSTEM`, `CONTRADICTS`), glow underlays, and enlightened hover tooltips detailing coupling physics and formulas.
- 🖐️ **Full Touchpad & Gesture Navigation**:
  - **Two-Finger Pan**: Smoothly travel and glide across the infinite canvas.
  - **Pinch-to-Zoom**: Fluid continuous zooming from $35\%$ to $250\%$ centered around your cursor focal point.
- ⚙️ **Engineering & Mathematical Viewports**:
  - Live 60fps SVG animated Chebyshev 4-bar straight-line crank mechanism with interactive speed multipliers.
  - Solid-state Drude-Lorentz optical conductivity spectrum chart.
  - KaTeX LaTeX mathematical proof models with screen-reader fallbacks.
- 📑 **Scholarly Embedded Browser (`z-70`)**: Slide-in panel for reading arXiv preprints with one-click "Map to Graph" extraction.
- 🔍 **Light Inspector Deck (`z-70`)**: Detailed node synthesis, mathematical breakdown, and live AI web investigation probe simulators.
- ⚡ **Obsidian Spark Terminal (`z-60`)**: Bottom floating command line with telemetry indicator for natural language query synthesis.
- ⌨️ **Keyboard Shortcuts**:
  - <kbd>Space</kbd>: Pause/Resume animations
  - <kbd>Esc</kbd>: Close drawers and modals
  - <kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd>: Zoom In / Out / Reset (100%)
  - <kbd>1</kbd>–<kbd>5</kbd>: Quick-inspect nodes
  - <kbd>T</kbd> / <kbd>S</kbd>: Focus Spark Terminal
  - <kbd>N</kbd>: Spawn Node from Template
  - <kbd>?</kbd>: Open Shortcut Guide

## Quick Start

### 1. Modern React Application (Vite)
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```

### 2. Standalone Single-File Preview
Simply double-click and open [`prototype_preview.html`](./prototype_preview.html) in any modern web browser—**no Node.js or build tools required**.

## Architecture

```
/src
  /components
    /nodes         # WebsiteNode, MechanismNode, TransportNode, TopologicalNode, ContradictionNode, SpawnedNode
    /ui            # SmartGlassPanel, OrganicLinkageLayer, ConvexHull, ClockTimerWidget, EmbeddedBrowser, NodeInspector, SparkTerminal, CanvasControls, KeyboardShortcutsModal, NodeTemplateModal
    /layout        # SpatialCanvas (touchpad pan & zoom, drag physics)
  /hooks           # useFluidPhysics, useOrganicLinkages, useNodeInspector
  /utils           # nodeTemplates, pathGenerator, mathRenderer, colorTokens, accessibilityHelpers
  /styles          # globals.css, tailwind.config.js
```
